# Guild Settings

Guild settings let you customise how your guild appears and how players join.

## Open the settings menu

| Command       | Description                                    |
| ------------- | ---------------------------------------------- |
| `/g settings` | Opens the guild settings menu. |

The settings menu currently shows whether the guild is open for anyone to join or invite-only.

## Banner

| Command                  | Description                            |
| ------------------------ | -------------------------------------- |
| `/g settings set-banner` | Sets the guild banner. |

You must be holding the banner you want to use.

:::info
The banner feature must be unlocked first using `/g unlock banners`.
:::

## Tag

| Command                     | Description                                       |
| --------------------------- | ------------------------------------------------- |
| `/g settings set-tag <tag>` | Sets the guild tag shown in chat. |

Guild tags must be **1-4 characters** long.

:::info
The tag feature must be unlocked first using `/g unlock tags`.
:::

## Description

| Command                                     | Description                                 |
| ------------------------------------------- | ------------------------------------------- |
| `/g settings set-description <description>` | Sets the guild description. |

The guild description can be seen in the guild UI when hovering over the nether star.

## Invite-only setting

| Command                           | Description                                                       |
| --------------------------------- | ----------------------------------------------------------------- |
| `/g settings set-invite-only on`  | Makes the guild invite-only.                      |
| `/g settings set-invite-only off` | Allows players to join without an invite/request. |
