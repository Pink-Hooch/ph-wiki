## Basic guild commands

| Command            | Description                                               |
| ------------------ | --------------------------------------------------------- |
| `/g <guild name>`  | Opens a guild's UI.                       |
| `/g settings`      | Opens your guild settings.                |
| `/g energy`        | Shows how much energy your guild has.     |
| `/g view <player>` | Shows the guild that a player belongs to. |
