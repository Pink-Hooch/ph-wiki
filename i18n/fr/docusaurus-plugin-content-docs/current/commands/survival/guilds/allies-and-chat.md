# Allies and Guild Chat

Guilds can ally with other guilds and use special chat channels.

## Allies

| Command                  | Description                                                      |
| ------------------------ | ---------------------------------------------------------------- |
| `/g ally <guild name>`   | Sends or accepts an alliance with another guild. |
| `/g unally <guild name>` | Removes an alliance with another guild.          |

## Chat channels

| Command        | Alias | Description                                  |
| -------------- | ----- | -------------------------------------------- |
| `/guild chat`  | `/gc` | Toggles or uses guild chat.  |
| `/master chat` | `/mc` | Toggles or uses master chat. |
| `/ally chat`   | `/ac` | Toggles or uses ally chat.   |

:::note
If these commands require a message after them, this page should be updated with examples.
:::

## Examples

```text
/gc Hello guild!
/ac Hello allies!
```
