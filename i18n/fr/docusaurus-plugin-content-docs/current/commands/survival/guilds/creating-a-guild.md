# Creating a Guild

You can create your own guild using `/g create`.

## Create a guild

| Command                  | Description                                           |
| ------------------------ | ----------------------------------------------------- |
| `/g create <guild name>` | Creates a guild with the chosen name. |

Creating a guild costs **$10,000**.

After running the command, a confirmation menu will appear where you can confirm or cancel the guild creation.

If the guild name is already taken, the request will be denied.

## Unlock guild features

| Command             |       Cost | Required Rank   | Description                                                |
| ------------------- | ---------: | --------------- | ---------------------------------------------------------- |
| `/g unlock banners` | `$150,000` | Elder or Master | Unlocks the ability to set a guild banner. |
| `/g unlock tags`    |  `$25,000` | Elder or Master | Unlocks the ability to set a guild tag.    |

Guild tags must be **1-4 characters** long.
