## Basic commands

| Command           | Description                                            |
| ----------------- | ------------------------------------------------------ |
| `/spawn`          | Return to spawn.                       |
| `/tpa <player>`   | Request to teleport to another player. |
| `/tpaccept`       | Accept a teleport request.             |
| `/sethome <name>` | Set a home location.                   |
| `/home <name>`    | Teleport to a saved home.              |
