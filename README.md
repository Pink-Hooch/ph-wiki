# Pink Hooch Wiki

This wiki is built using [Docusaurus](https://docusaurus.io/), a modern static website generator.

## Contributing

We suggest using [VS Code](https://code.visualstudio.com/) or [JetBrains WebStorm](https://www.jetbrains.com/webstorm/) as your IDE.

NodeJS is required to run this wiki locally. Link to the [Node JS download page](https://nodejs.org/en/download/).

Install the dependencies with: `npm install`

Start the development server with: `npm run start`

The website will be available at `http://localhost:3000`. It will automatically reload if you make edits.

You may contribute to this wiki by editing the markdown files in the `docs` directory.
Open a pull request with your changes for review.
