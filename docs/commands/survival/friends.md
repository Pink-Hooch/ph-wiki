# Friends

The friends system lets you manage friend requests from other players.

## Friend commands

| Command | Description |
| --- | --- |
| `/friends add <player>` | Sends a friend request to a player. |
| `/friends remove <player>` | Removes a player from your friends list. |
| `/friends accept <player>` | Accepts a friend request. |
| `/friends ignore <player>` | Ignores that player's friend requests. |

## Examples

```text
/friends add Steve
/friends accept Alex
/friends remove Steve
/friends ignore Alex

If someone is bothering you with friend requests, use /friends ignore <player>.
