# Guild Homes and Claims

Guild homes and claims help your guild protect land and quickly return to important locations.

## Guild homes

| Command | Description |
| --- | --- |
| `/g sethome <home name>` | Sets a guild home. |
| `/g home` | Teleports you to the guild home. |
| `/g delhome` | Deletes the guild home. |

:::note
If multiple guild homes are supported, this page may need updating to show the correct usage for `/g home` and `/g delhome`.
:::

## Guild claims

| Command | Description |
| --- | --- |
| `/kit guildclaim` | Gives you the guild claim axe. |
| `/abandonclaim` | Abandons the claim you are currently standing in. |
| `/abandonallguildclaims` | Abandons all claims owned by your guild. |

The guild claim axe works like a claim shovel, but creates claims for your guild instead of just your player.

:::warning
`/abandonclaim` is also used for normal player claims. Make sure you are standing in the correct claim before using it.
:::

:::danger
`/abandonallguildclaims` removes all guild claims. Only use this if you are completely sure.
:::
