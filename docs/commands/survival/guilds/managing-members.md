# Managing Guild Members

These commands are used to manage players in your guild.

Some commands may require a higher guild rank.

## Invites

| Command | Description |
| --- | --- |
| `/g invite <player>` | Invites a player to your guild. |
| `/g uninvite <player>` | Removes an invite sent to a player. |

## Ranks

| Command | Description |
| --- | --- |
| `/g promote <player>` | Promotes a player to the next guild rank. |
| `/g demote <player>` | Demotes a player to the rank below. |
| `/g setrank <player> <rank>` | Sets a player's guild rank. |

## Removing members

| Command | Description |
| --- | --- |
| `/g kick <player>` | Kicks a player from the guild. |

## Transferring ownership

| Command | Description |
| --- | --- |
| `/g transfer <player>` | Transfers ownership of the guild to another player. |

When ownership is transferred, the chosen player becomes the **Elder**, and you become **Master**.

## Disbanding a guild

| Command | Description |
| --- | --- |
| `/g disband <guild name>` | Disbands the guild. |

:::danger
Only the Elder can disband a guild. Disbanding a guild may be permanent.
:::
